# Handoff

## Status

Nested projects (workstreams) feature is complete and deployed. Commit 93ea5e7.

## What's new

Projects now support parent/child hierarchy via slash-separated slugs:

```
yojana projects              # root projects only (default)
yojana projects chitta       # detail + workstreams table
yojana tasks chitta          # rolls up tasks from all descendants
yojana tasks chitta/research # just that workstream
yojana tasks chitta/research/1  # task detail
```

Creating `chitta/research` auto-sets parent to `chitta`. MCP tool `yojana_project` accepts optional `parent` param for list filtering.
